How does a skill work?

A skill is a folder your agent reads: a SKILL.md instruction file plus the templates, scripts and reference files it needs. You install it once into your agent's skills directory, then ask for the output in plain language. The skill runs locally in your own agent — AI Frontier Skills does not host your prompts or your model calls.

1. Download the ZIP and unzip it into your agent's skills folder
   (for Claude Code: ~/.claude/skills/)
2. Restart your agent
3. Ask: "Make me a stickman explainer video about how DNS works"

Why pay for a skill you could write yourself?

You are paying for the finished output, not the file. Every premium skill here was reverse-packaged from a real, published output — an illustration set, a rendered video, a running channel — and is maintained as agent platforms change. The free starter skill lets you judge the quality before you spend anything: no card, no trial timer.

Frequently asked questions

What exactly do I receive when I buy a premium skill?

You receive a ZIP containing the SKILL.md instruction file, templates, scripts, an install guide, worked examples, a license and a changelog. Updates within the same major version are included.

Which agents are supported?

Any agent that follows the Agent Skills open standard, including Claude Code, Codex and Cursor. Each skill page lists the platforms it was tested on.

Is AI Frontier Skills a marketplace?

No. It is not a marketplace and there is no community upload. Every skill is designed, written and tested by the AI Frontier Skills team.

How much does it cost?

The starter skill is free. Premium skills cost $4.99 each, and a bundle of all premium skills is planned at $39. Prices on this page, the pricing page and each skill page are the same.

Do skills run in the cloud?

No. A skill is installed into your own agent on your own machine and runs there. Your model usage and API costs are separate and are not included.

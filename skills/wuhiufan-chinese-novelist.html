What problem does it solve?

Coherence across 10–50 chapters. A three-layer Q&A builds the core setup, the customization and the title before drafting starts. A creation-memory system tracks characters, relationships and planted foreshadowing across the run, and the project can be interrupted and resumed without losing the thread. Two rules do the daily work: every chapter carries conflict or a turn, and every chapter ends on a hook. A de-template-tone polish pass is built into the flow.

Who is it for?

Writers of Chinese long-form web fiction — suspense, romance, fantasy, sci-fi, historical — who want a coherent serial rather than fifty disconnected chapters. The skill's guides and prompts are in Chinese; this page is in English so you can evaluate it first.

What do you get?

  • SKILL.md: the full workflow — three golden rules, phased planning, interrupt-and-resume for unfinished projects
  • references/flows: the phase-by-phase process, initialization to final validation
  • references/guides: chapter writing, character building, dialogue, hook techniques, plot structures, outlining, content expansion
  • scripts/: Node.js helpers with tests — chapter word-count check, project validation, chapter-summary initialization (verified working, 6/6 tests each)
  • An English install guide

Honest limitations

The skill structures and disciplines the writing; it does not guarantee platform acceptance, readership or income. Output quality still depends on the model you run it with and the outline you approve in phase one — a weak outline produces a well-organized weak novel.

Frequently asked questions

The skill is in Chinese. Is that a problem if my Chinese is rusty?

The output fiction is Chinese — that is the product. The package adds an English install guide and this page, but the guides and workflow speak Chinese because the novels do. If you do not write Chinese fiction, this one is not for you.

How does it stop the plot from drifting?

A creation-memory layer: character sheets, relationship state and a foreshadowing ledger are maintained as project files and checked at validation gates between phases, instead of living in the model's memory of the conversation.

Can it continue a novel I already started?

Yes — the workflow detects unfinished projects and resumes from the breakpoint, using the memory files to rebuild context.

What exactly do I receive?

A ZIP with the skill folder: SKILL.md, flow and guide references, the Node scripts with tests, the original MIT license, attribution, an English install guide and a changelog.

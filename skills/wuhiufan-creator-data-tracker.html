What problem does it solve?

If you post on more than one platform, your numbers live in five different analytics pages, each with its own layout and its own definition of "views". So the real questions — which platform is actually growing? Did this week beat last week? What did that series earn? — get answered by vibes, or by an hour of copying figures into a blank sheet that goes stale the moment you finish it. Most creators either pay for a dashboard tool every month or quietly stop tracking altogether.

How does it work?

One workbook, three working sheets. Log — one row per post: date, platform, account, title, link, type (dropdown: video / image post / long-form / short post), views, likes, comments, shares, saves, new followers, revenue. Weekly — automatic rollups per week per platform built on SUMIFS/COUNTIFS formulas. Dashboard — all-time totals (posts, views, interactions, revenue) plus a per-platform table with an engagement-rate column. It ships with 12 clearly marked sample rows, fictional handles and numbers on light-yellow shading, so you can watch every formula work before typing a single real figure; delete them and the workbook resets to zero around your own data.

What is inside the package?

  • Wuhiufan-Creator-Data-Tracker.xlsx — the workbook: Log, Weekly, Dashboard and an in-sheet ReadMe
  • README.md — bilingual (English / Chinese) quick-start and formula notes
  • LICENSE.txt — single-user license (English / Chinese)
  • Dual format, one file: the same .xlsx opens directly in Excel and imports into Google Sheets (File → Import → Upload) with all formulas intact
  • Formulas pre-extended to row 1000 of the Log — roughly two years of daily posting across four platforms

Honest limits

This is a tracking workbook, not an analytics service: it does not fetch platform data automatically — you type the numbers in, which is also why it works for any platform, including ones no dashboard tool supports. Weekly rollups are grouped by the week-start dates you set; adding a new week means copying a block of rows and changing two dates, which the ReadMe walks through.

Frequently asked questions

Excel or Google Sheets?

Both. One .xlsx file opens in Excel as-is and imports into Google Sheets with formulas intact. Buy once, use it in whichever one you live in.

Is there a subscription?

No. One-time purchase, and free updates of this workbook are included.

Can I track platforms beyond the samples?

Yes. Platform is a free-text column and every rollup keys off it, so any platform you type is picked up automatically.

What do I need to run it?

Microsoft Excel, Google Sheets, or any spreadsheet app that reads .xlsx formulas (LibreOffice Calc works too).

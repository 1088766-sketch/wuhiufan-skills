Frequently asked questions

What is the current status of this skill?

In production. Version 2 of this workflow was rebuilt around real sourced media after the placeholder-card version failed quality review.

Which platforms is the output sized for?

1080x1920 vertical MP4 for YouTube Shorts, Reels and similar vertical feeds.

Does it generate the video, or use real material?

Real material. Each short is built from the source item's actual photos, with voiceover and burned-in subtitles — no generated footage pretending to be the news. That is a deliberate credibility choice, and the workflow enforces it.

How long is each short, exactly?

About 20 seconds, vertical, sized for Shorts and Reels. The script format is written backwards from that limit: one news item, one point, no filler.

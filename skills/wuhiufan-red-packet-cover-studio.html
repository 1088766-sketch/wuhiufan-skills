What problem does it solve?

Most people make a cover by generating a pretty vertical picture and uploading it. Then the platform crops it, the interface covers the subject, any text in the image comes out garbled, and the file fails a size or weight check. Fixing any of that means starting over, because there was never a workflow — just one lucky-or-unlucky image.

What is inside the package?

  • Brief intake that asks only what matters — occasion, subject (text brief or your own reference photo), greeting text, style, palette; sensible defaults fill the rest, stated out loud
  • A canvas and safe-zone system — vertical 3:4 design with a calm top band for the avatar and greeting overlay, a clear bottom band for the button, and a central safe zone where the hero subject lives
  • A 16-style house library — porcelain blue-and-white, paper-cut folk, claymation, pixel lantern town, neon night market, origami minimal, and ten more, each a generation-ready description
  • A real approval gate — you approve the raw artwork before anything else happens; revisions change the artwork, never a patched preview
  • A simulated preview mock — your approved artwork composited, unmodified, into a labeled mock of the packet screen, so overlay collisions are caught while still cheap to fix
  • A spec-checked export — dimensions, format, file weight, crop, text, and safe-zone checks run against the exported file itself

Honest limitations (please read)

Design output, not an official template: the skill produces original artwork, a clearly labeled simulation preview, and an upload-ready file; the simulation is a composition aid, not a WeChat template, and the preview image itself is never upload material. Publishing is WeChat's process, not ours: real covers go live only through WeChat's official Red Packet Cover platform, which sets its own eligibility requirements, technical specifications, and review; the skill never uploads or operates your account, and it cannot promise a cover will pass review. Specifications change: export sizes and limits are working values, and the skill instructs you to verify the current numbers on the official platform before uploading. Image generation is required; without one, the skill delivers a production-ready prompt and layout specification instead of pretending an image exists. Strongly seasonal: demand and review queues peak before Lunar New Year — start weeks ahead, not days.

Frequently asked questions

Is this an official WeChat template?

No. It designs original artwork plus a labeled simulation. Publishing still goes through WeChat's official Red Packet Cover platform and its review.

Can it upload the cover for me?

No. The skill never operates your account; it hands you an upload-ready, spec-checked file.

What do I need to run it?

Any agent runtime that supports SKILL.md skills, plus an image generation or editing tool for the design steps.

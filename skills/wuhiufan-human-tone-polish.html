What problem does it solve?

Machine-assisted drafts share the same handful of habits: sentences that invent a misunderstanding just to knock it down, colons that announce a conclusion before making it, the same concept renamed five ways in one paragraph, every paragraph chained politely to the last, and three sentences in a row built on the exact same skeleton. Readers feel it instantly — and word-ban lists don't fix it, because the problem is structure, not vocabulary. Worse, aggressive "make it sound human" prompts mangle the parts that were already fine: real writers use numbered headings, rhetorical questions and restatements all the time.

How does it work?

1. Scan — mark hits against seven documented template patterns; nothing is edited yet. 2. Minimal edit — fix only the marked spots under strict rules: smallest possible change, every fact and hedge conserved, structure frozen, the author's own voice guide outranks the checklist. 3. Re-scan — verify every edit maps to a marked hit, nothing from the protected never-touch list was removed, and no rhythm was artificially scrambled. The never-touch list is half the product: numbered subheadings, lead-in-plus-list, general-then-specific paragraphs and rhetorical questions are explicitly protected.

What is inside the package?

  • README.md — install instructions (one folder copy, zero dependencies, no API keys)
  • Works on Chinese and English drafts; patterns are described structurally, not as a phrase blacklist, so they survive paraphrase

Honest limits

This is an editing discipline, not an authorship certificate. It removes documented template habits; no skill can guarantee a draft passes any third-party detector, and this one doesn't claim to. It polishes finished drafts — it does not write them, fact-check them, or judge metaphors. Results depend on the model running the skill following the scan-first order; skipping the scan and free-editing is exactly the failure mode the workflow exists to prevent.

Frequently asked questions

Is this just a banned-word list?

No — the skill explicitly forbids judging by word lists. Every pattern is a sentence- or paragraph-level structure.

Will it change my meaning?

The minimal-edit rules make information conservation a hard constraint: facts, numbers, quotes and hedges must survive, and the re-scan reverts any edit that can't be traced to a marked hit.

Chinese or English?

Both. The patterns are stated structurally, with recognition cues for drafts in either language.

What do I need to run it?

Any agent runtime that supports SKILL.md skills. No scripts, no dependencies, no keys.

FAQ

Why Markdown files instead of a database or a memory app?

Because every agent can read them, you can read them, git gives you history and undo, and nothing is locked inside one vendor's app. Plain files are the only format all your tools already speak.

Do my different agents really share one memory with this?

Yes — that is the design. Each agent gets a short adapter pointing at the same vault, and its built-in auto-memory is demoted to scratch so the vault stays the single source of truth.

Can I put API keys or passwords in the vault?

No — and the skill says so in bold. The vault is working context that tools read freely; credentials belong in a password manager or a secrets vault, never in these files.

How much upkeep does it actually take?

About fifteen minutes a week: clear the inbox, merge duplicates, archive finished projects. The skill gives the exact checklist.
